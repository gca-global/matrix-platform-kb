# ADR-036: Property/project listings are a tenant-shared catalog with opt-out private visibility

**Status**: Accepted
**Date**: 2026-07-04
**Deciders**: Platform team + Qobrix Sales Automation team
**Related**: [security-model.md](../../platform/security-model.md) (Pattern B vs catalog), [tenant-role-configuration.md](../../platform/tenant-role-configuration.md), [ADR-012](ADR-012.md) (JWT-only RLS helpers)

## Context

Qobrix Sales Automation mirrors `properties` and `projects` in the App DB (`ycbwgnihbrqammkgngum`). Migration `20260703150000_team_scoped_rls_owner_team_id.sql` applied owned-record Pattern B (`can_read_scoped_row`) to these tables, which incorrectly restricted listing visibility to self/team scope.

Brokerage practice: **listings are a tenant-wide catalog** unless explicitly marked private. Contacts, opportunities, offers, and activities remain owned records.

## Decision

### D1 — Catalog SELECT policy

`properties` and `projects` use a catalog read function:

```sql
tenant_id = get_current_tenant_id()
AND (
  is_private = false
  OR created_by = get_current_user_id()
  OR get_active_scope() IN ('global', 'org_admin', 'system_admin')
)
```

### D2 — `is_private` column

Add `is_private boolean NOT NULL DEFAULT false` to `properties` and `projects`. Default = visible to all authenticated users in the tenant.

### D3 — Writes stay owned-record scoped

INSERT/UPDATE/DELETE policies remain Pattern B (creator + team overlap + elevated scopes). A broker cannot edit another agent's listing even when it is public.

### D4 — Qobrix historical reads unchanged

Rows with `row_source=qobrix` continue to flow through Qobrix edge functions with per-user session scoping. This ADR governs **App DB catalog rows only**.

## Consequences

### Positive
- Brokers see the full non-private listing catalog within their tenant.
- Private listings support off-market / exclusive workflows without team leakage.
- Aligns with HRMS public-directory and ITSM catalog patterns.

### Negative
- App DB listing count queries return all tenant listings (expected for catalog UX).
- UI must expose `is_private` on editable App DB properties.

## Implementation

- Migration: `matrix-qobrix-sales-automation-rls/supabase/migrations/20260704100000_catalog_listings_is_private.sql`
- UI: Private toggle in `PropertyDetailDrawer` for `editable` App DB rows; badge on `PropertyCardTile`
