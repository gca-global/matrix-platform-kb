## Key Concepts

- **Sharp Matrix Platform**: Multi-app ecosystem with RESO DD 2.0 as canonical data layer
- **3 Markets**: Cyprus (core), Hungary (growth), Kazakhstan (emerging luxury)
- **4 Client Segments**: UHNWI (€2M+), HNWI (€1-2M), Standard (€300K-1M), Mass (<€300K)
- **4 Elements of the Model**: Commission Funnel, Listings, Appointments, Follow-ups
- **2 Representations**: matrix-pipeline CRM (canonical 5-stage funnel projection: Qualification → Matching → Viewing → Contracting → Payment) + AI Brokerage Copilot for brokers
- **AI Copilot**: Context analysis → Next Best Action → Automated routines (FR-AI-LQ / MX / SC / DM in the matrix-pipeline product spec)
- **Dual focus**: `Property` listings (managed in Listing Module) + `Contacts × SavedSearch` buyer intents (managed in matrix-pipeline)
- **Matching Engine**: AI connects listings ↔ buyer intents via `ContactListings` + `Caravan` curated lists
- **Trigger Boundary**: first `Showing` event marks `ContactType` graduation from Prospect into Ready-to-Buy
- **7-Phase Roadmap**: Jan 2026 → Feb 2027, from foundation to full integration
- **Target**: 90%+ automation, 50-day sales cycle, €115K client LTV
